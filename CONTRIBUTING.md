# Contributing

## Developer Certificate of Origin

This project uses the Developer Certificate of Origin (DCO) 1.1 instead of a Contributor License Agreement. The full text of the DCO is available at https://developercertificate.org/.

By contributing, you certify the statements in the DCO for your contribution. To record that, add a `Signed-off-by` line to every commit, using your real name and an email address you can be reached at:

```text
Signed-off-by: Your Name <you@example.com>
```

`git commit -s` adds the line automatically using your configured `user.name` and `user.email`.

## Ground rules

- Do not commit secrets, credentials, personal information, real conversation logs, or non-public identifiers — including in examples and test fixtures. Use synthetic values only.
- Keep changes scoped to one topic per pull request, and describe what changed and why.
- Specifications and code are both licensed under Apache-2.0 (see LICENSE).

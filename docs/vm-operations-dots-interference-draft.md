- 干渉する：(2) と J3・隔離境界の制約、(3) と J4、(4) と J3。計 4 件。いずれも (e) 側で既に整理が進んでいる項目と、段階 4 側の移転対象が同じ作業・同じ対象版・同じ制約を扱うものである。

## 3. 調整で決めるべき論点の一覧

以下の論点は、siro との調整で決めるべき事項である。各論点の推奨判断は mugi 側の草案であり、決定ではない。決定は siro との調整で行う。

### 論点 1：開始時期

- 論点：段階 4 の開始時期を、(e) の開始条件整理の結論を待つか、先行して進めるか。#64 本文の前提「段階 3 までが済んでいること」との関係も含む。
- 現況：(e) は開始保留中である（siro、ts 1794281574.056309）。段階 3 の実施・送信は未了である。
- 推奨判断の草案：段階 4 のドラフト共有（本書の内容の共有）までは、(e) の開始を待たずに進めてよい。計測の実証・適用（#64 の受入条件 1・2 に当たる実施）は、(e) の開始条件が確定してから行う。開始時期の最終決定は siro との調整に委ねる。段階 3 の完了を段階 4 のドラフト共有の前提としない（単位定義の依存分離どおり）。

### 論点 2：範囲
